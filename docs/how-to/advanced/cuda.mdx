# Build NVIDIA CUDA packages

The following guides cover building conda-forge packages that depend on the CUDA Toolkit. They assume familiarity with writing recipes for compiled code (see [Compilers and Runtimes](/docs/maintainer/infrastructure/#compilers-and-runtimes)) and with the user guide for [running CUDA code](/docs/user/cuda/).
