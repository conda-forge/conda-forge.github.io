# How to configure a feedstock for CUDA

This guide covers the feedstock configuration for packages that depend on CUDA. To support ARM Tegra devices, see [how to build for ARM Tegra devices](/docs/how-to/advanced/cuda/tegra/).

## Cross-compile

The CUDA compiler toolchain supports cross-compilation in the same way as other compiler toolchains on conda-forge. See the [cross-compilation documentation](/docs/how-to/advanced/cross-compilation/) for more information.

## Run builds on GPU runners

By default, provisioned CI machines do not feature a GPU. See [how to configure self-hosted runners](/docs/how-to/advanced/self-hosted-runners/) if your feedstock needs access to additional resources like GPUs or long-running builds.

## Adopting a new CUDA version

As new CUDA versions come out regularly, periodically conda-forge needs to decide how many versions will be supported within resource constraints. As of August 2026, conda-forge supports CUDA 12 and 13.

conda-forge manages the adoption of a new CUDA major version with a [migration](/docs/maintainer/knowledge_base/#migrators-and-migrations). The migration bot opens a pull request in your feedstock with the changes needed to build for the new version.

To update to the latest supported versions outside of a migration, or if your feedstock no longer builds old CUDA versions, [rerender the feedstock](/docs/how-to/basics/rerender/). There may be other fixes needed for the feedstock depending on when it was last updated.
