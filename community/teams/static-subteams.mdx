# Static sub-teams

As per the [governance](../governance.md), the conda-forge community is organized in several teams.
The core team may create sub-teams to manage the daily business of the organization. Sub-teams have either a static or dynamic charter.
In static sub-teams, all membership decisions and non-trivial policy changes of these sub-teams must be approved by the core team.
The list below is automatically generated from the metadata collected in
[`conda-forge/governance`](https://github.com/conda-forge/governance/tree/main/teams).
